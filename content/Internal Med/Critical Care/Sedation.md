there is both ICU continuous sedation and procedural sedation 

Propofol
	provides ONLY sedation without any analgesia
	+ves = fast on/ fast off,  titratable, cheap 
	-ves = ↓ BP & HR (worse with pushes), resp depression, PRIS (rhabo, arrhythmias, 40% mortality)
	dosing 
		infusion = 0-60 mcg/kg/min (in OR can do much higher since short period)
		push dosing 
	do not like to use it in CCU due to myocardial depression
	should only use this if you can intubate (eg. in ICU, ED) 

Ketamine
	provides sedation AND analgesia (and usually amnestic but not always)
	3 dosing ranges
		0.1-0.3 mg/kg = analgesia (no dissociative effects, APS dosing) 
		0.5 mg/kg = + dissociation eg. for shoulder reduction, cardioversion etc (may have ketamine stare)
		1-2 mg/kg (ie. 100mg) = anesthesia, may be used for continuous sedation in ICU but hard to judge
	sometimes can give some benzos eg. midaz since dissociation can be bad and they can freak out
	stimulates sympathetics so usually no effect on BP since offsets the sedation but can cause HTN/ tachy so not always like in cardiac pts; if alr max catecholamined and then give ketamine may have hypoT 

Midazolam
	provides ONLY sedation (and amnesia), no analgesia
	+ves = fast on/ ~off, retrograde amnesia, relatively hemodynamically stable
	-ves = accumulates badly if organ dysfunction, deliriogenic (highest association) 
	dosing
		infusion 0-10 mg/h = continuous sedation 
		push 1-2mg IV push = good for procedures eg. cardioversion, 
	since no analgesia, usually combined with fentanyl (but caution resp depression from both agents)

Fentanyl (not really sedative)
	dosing
		infusion 0-250 mcg/h 
		push dose 25-50mcg 

Precedex 
	this is essentially IV clonidine
	no resp depression; bradycardia hypotension is the problem
	usually just as an infusion and titrate

For procedures
	if will paralyze someone (eg. trach insertion) NEED sedation so they are not awake and paralyzed

Examples scenarios
	Unstable cardioversion = v low dose fentanyl (25mg) and some midaz (1mg)
	Stable cardioversion = push dose propofol (fast on, fast off)
