<u>HIV tx</u>
historically, always tx with 3 fully active agents
	this is because it is a retrovirus which uses reverse transcriptase which is v error prone which allows variations in the RNA produced which can ultimately allow for evasion of 1 drug if only using one
with time, we found that even with 2 active agents can get HIV suppressed
	but alot of pts are still on Biktarvy (which has 3 agents) - very great drug with low resistance, but ↑ metabolic and CV complications
	now we are trying to transition to just do 2 drug combo eg. Dovato
categories = NRTI or NNRTI (target reverse transcriptase), INSTI (integrase inhibitor), PI (protease inhibitor)
	need to create a combo of 2 DIFFERENT categories of HIV med 
	note: NRTI and NNRTI count as 2 diff agents 
some pts can be on more than 2 agents - this tells you that they prob have some underlying resistance and not a usual wild type virus 
renal dosing
	CrCl <30 - should not be using tenofivir, but irl/ practically can keep going till CrCl <15 with tolerable s/e 
PrEP uses just 1 drug class (but 2 agents from the same class) = TAF+FTC (both NRTI) or TDF+FTC
there are now even injectable forms of some drugs and even for PrEP
	problem with injectables - if get an injection and pt doesn't return for other injection then after the injection wears off, they have lingering subtherapeutic lvl of drug for a long time and if they get exposed to HIV can get resistance
what if pt is on PO not cant take PO meds
	no IV substitute realistically
	insert NG and use med that can be crushed 
	if GI tract not working then can explore injectable options
